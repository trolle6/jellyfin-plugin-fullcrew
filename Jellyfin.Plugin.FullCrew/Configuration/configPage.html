Full Crew

Shows a categorized full cast & crew accordion on movie and series detail pages in Jellyfin Web, using live TMDB credits (Camera, Costume & Make-Up, Sound, VFX, and more).

Leave blank to use Jellyfin’s built-in shared TMDB key (same as the official TheMovieDb provider). Only set your own key if you want separate rate limits / usage tracking — free keys at themoviedb.org/settings/api.
How long to cache TMDB credits in memory (1–168).

Library stats

Adds a Library Stats page with genre, studio, people-by-role, rating, tag, and runtime breakdowns.
Release years lists every year that has titles — no Top-N cutoff or “Other” bucket. You can also change this on the Stats page itself.

Audio type browser

Browse every commentary, description, dub, or labeled extra audio track across the library without picking a show first. Uses the audio stream title stored in the file.

Playback characters

On Jellyfin Web playback, press Y (or the people button on the player) for a side panel of billed characters: character name, actor name, and a still from this title when TMDB has one. The video keeps playing. Full departments stay on the title page — back out of playback and scroll the accordion. This is not Amazon X-Ray.

Scene identify (optional)

Unused by the playback panel. Leave off unless you call the identify-frame API yourself. When enabled, a still can be sent to OpenAI Vision to match billed cast.

Required when scene identify is enabled. Stored in plugin config like other secrets. Keys from platform.openai.com/api-keys.
Default gpt-4o-mini. Use a vision-capable chat model.

Break bumpers

Optional. Prefer clips from a collection or folder with this name (default: Bumpers). Also matches library items tagged or named with “bumper”. Already-seen bumpers rotate per show; use Another bumper in the overlay for the next clip.

Departments

Choose which departments appear in the accordion.

Web UI injection

Replaces the solid green circle on episode thumbnails in series/season lists. Movie/show cards and other play buttons are unchanged.

The plugin injects a script into Jellyfin Web. Prefer installing the File Transformation plugin for Docker-safe injection. Otherwise the plugin will try to patch index.html, or you can add: 

<script plugin="FullCrew" src="/FullCrew/fullcrew.js"></script>

After installing, restart Jellyfin and hard-refresh the web client.
